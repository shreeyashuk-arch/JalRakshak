# JalRakshak Edge AI Pipeline

**Predict the Failure. Protect the Water.**

This module implements the time-series signal conditioning, feature extraction, baseline model training, and edge inference pipeline for pump degradation detection.

---

## 1. Pipeline Overview

```
Raw Time-Series (Vibration, Current, Temp, Flow)
                    ↓
        Feature Extraction (RMS, Crest, Var, Flow-Eff)
                    ↓
        Baseline Classifier (Trained Random Forest / TinyML)
                    ↓
        Health Classification: HEALTHY | DEGRADING | CRITICAL
                    ↓
        Anomaly Score (0.0 to 1.0) & Pump Health Score (100% to 0%)
```

---

## 3. Deployment to Nordic nRF54LM20 DK

The features extracted here mirror the exact C implementations in `firmware/src/ai/edge_ai_engine.c`. For the nRF54LM20 DK:
- Fast float computation is accelerated via the ARM Cortex-M33 FPU (`CONFIG_FPU=y`).
- For the `nrf54lm20b` SoC revision, the Axon NPU can accelerate quantized INT8 networks.
